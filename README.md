# rental-platform-web

Aplicacion web para **Habitar Propiedades 2.0**, una plataforma de garantias de arrendamiento en Colombia. Este proyecto maneja toda la interfaz de usuario del sistema operativo interno: gestion de expedientes, inmuebles, arrendatarios, documentos, contratos, pagos, facturacion y vitrina publica.

## Stack

- **Next.js 16** (App Router, Turbopack)
- **React 19**
- **TypeScript**
- **Tailwind CSS 4**

## Inicio rapido

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Scripts

| Comando | Descripcion |
|---------|-------------|
| `npm run dev` | Servidor de desarrollo con Turbopack |
| `npm run build` | Build de produccion |
| `npm start` | Servidor de produccion |
